# DukaanSe - Product Management Dashboard

A responsive Product Management Dashboard built with **Next.js (App Router)** and **Tailwind CSS**.

## Features Implemented
- **Product Listing**: Displays product name, category, price, stock, and image dynamically.
- **Search**: Search products by title using Enter or search trigger.
- **Category Filtering**: Dynamic category pills generated from API data.
- **CRUD Operations**: Add (POST), Edit (PUT), and Delete (DELETE) products.
- **Form Validation**: Strict client-side checks for required fields, price, and URL format.
- **UI States**: Handles Loading, Error, Empty, and Success states smoothly.
- **Responsive Layout**: Designed for mobile and desktop screens.

## Technology Used
- **Framework**: Next.js (App Router)
- **Language**: JavaScript (ES6+ / JSX)
- **Styling**: Tailwind CSS
- **API**: DummyJSON REST API (`https://dummyjson.com/products`)
